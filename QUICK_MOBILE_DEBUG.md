# Быстрая инструкция: Логи на мобильном БЕЗ компьютера

## Самый простой способ (Eruda)

### Шаг 1: Откройте сайт на телефоне
https://newava.pro/

### Шаг 2: Скопируйте и вставьте в адресную строку:

```
javascript:(function () { var script = document.createElement('script'); script.src = '//cdn.jsdelivr.net/npm/eruda'; document.body.appendChild(script); script.onload = function () { eruda.init(); } })();
```

### Шаг 3: Нажмите Enter

Внизу экрана появится панель с инструментами разработчика.

### Шаг 4: Откройте консоль

1. Нажмите на иконку **Console** (вторая слева)
2. Теперь все логи будут видны здесь!

### Шаг 5: Загрузите фото

1. Попробуйте загрузить фото
2. В консоли появятся логи
3. Скопируйте или сделайте скриншот логов

---

## Что искать

После загрузки фото в консоли должны появиться:

1. **`[App] File selected:`** - информация о файле
2. **`[evaluateImage] Starting evaluation`** - начало проверки
3. **`[evaluateImage] Error caught:`** - если есть ошибка (красным)

---
