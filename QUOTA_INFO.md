# 📊 Информация о квотах Gemini API

## 🔍 Типы квот

Gemini API имеет несколько типов квот:

### 1. **Минутная квота** (Per Minute)
- **Метрика:** `GenerateRequestsPerMinutePerProjectPerModel-FreeTier`
- **Восстановление:** Каждую минуту
- **Из логов:** `Please retry in 24.80309057s` (около 25 секунд)

### 2. **Дневная квота** (Per Day)
- **Метрика:** `GenerateRequestsPerDayPerProjectPerModel-FreeTier`
- **Восстановление:** Каждые 24 часа (обычно в полночь по UTC)
- **Из логов:** `limit: 0` означает полное исчерпание

### 3. **Квота токенов** (Input Tokens)
- **Метрика:** `generate_content_free_tier_input_token_count`
- **Восстановление:** Зависит от типа (минутная/дневная)

---

## ⏰ Когда восстановится квота?

### Для `gemini-2.0-flash` (анализ):
- **Минутная квота:** Восстановится через ~25 секунд (согласно логам)
- **Дневная квота:** Восстановится через 24 часа (обычно в полночь UTC)

### Для `gemini-2.5-flash-image` (генерация):
- Может иметь другие лимиты
- Проверьте на https://ai.dev/usage?tab=rate-limit

---

## ✅ Что делать?

### Вариант 1: Подождать (рекомендуется)
1. **Минутная квота:** Подождите 1-2 минуты и попробуйте снова
2. **Дневная квота:** Подождите до следующего дня (обычно полночь UTC)

### Вариант 2: Проверить статус квоты
- Откройте: https://ai.dev/usage?tab=rate-limit
- Войдите с аккаунтом, к которому привязан API ключ
- Проверьте текущее использование и лимиты

### Вариант 3: Upgrade плана (если нужно больше квоты)
- Перейдите на платный план Gemini API
- Это увеличит лимиты запросов и токенов

---

## 🔧 Проверка квоты на сервере

Используйте скрипт `check-both-quotas.bat` для проверки ошибок квоты в логах обоих сайтов.

---

## 📝 Примечания

- **Free Tier** имеет ограниченные квоты
- Разные модели (`gemini-2.0-flash` vs `gemini-2.5-flash-image`) имеют **отдельные квоты**
- Один API ключ может иметь разные квоты для разных моделей
- Квота восстанавливается автоматически по расписанию (минутная/дневная)
