# Инструкция по диагностике проблемы на мобильном устройстве

## Шаг 1: Откройте консоль разработчика на мобильном

### Для Android (Chrome):
1. Подключите телефон к компьютеру через USB
2. На телефоне: Настройки → Для разработчиков → Отладка по USB (включить)
3. На компьютере откройте Chrome
4. Перейдите на `chrome://inspect`
5. Найдите ваш телефон и нажмите "inspect"
6. Откройте вкладку "Console"

### Для Android (без USB - удаленная отладка):
1. На телефоне откройте Chrome
2. Перейдите на сайт https://newava.pro/
3. В адресной строке введите: `chrome://inspect`
4. Или используйте приложение "Eruda" для мобильной консоли

### Альтернатива - Eruda (проще):
1. Добавьте в адресную строку: `javascript:(function () { var script = document.createElement('script'); script.src = '//cdn.jsdelivr.net/npm/eruda'; document.body.appendChild(script); script.onload = function () { eruda.init(); } })();`
2. Или установите расширение для мобильного браузера

## Шаг 2: Попробуйте загрузить фото и посмотрите логи

После загрузки фото в консоли должны появиться логи вида:
- `[evaluateImage] Starting evaluation`
- `[evaluateImage] Sending request to: ...`
- `[evaluateImage] Fetch error:` (если есть ошибка)
- `[evaluateImage] Error caught:` (если есть ошибка)

## Шаг 3: Что искать в логах

### Если видите "Fetch error":
- Проверьте `error.message` - там будет детальная информация
- Проверьте `apiUrl` - правильный ли URL
- Проверьте `isOnline` - есть ли интернет

### Если видите "Response error":
- Проверьте `status` - код HTTP ошибки
- Проверьте `errorData` - что вернул сервер

### Если видите "timeout":
- Запрос превысил таймаут (60 секунд)
- Возможно, медленное соединение

## Шаг 4: Проверьте размер файла

В логах должно быть:
- `estimatedSizeMB` - размер изображения в MB
- Если больше 7MB - это проблема

## Шаг 5: Проверьте формат файла

В логах должно быть:
- `fileType` - тип файла
- Должен быть: `image/jpeg`, `image/png`, или `image/webp`
- Если другой формат (например, HEIC) - это проблема

## Возможные проблемы и решения

### Проблема 1: Файл слишком большой
**Решение:** Уменьшите размер фото перед загрузкой

### Проблема 2: Неподдерживаемый формат (HEIC)
**Решение:** Конвертируйте фото в JPG/PNG

### Проблема 3: Сетевая ошибка
**Решение:** Проверьте интернет-соединение, попробуйте другую сеть

### Проблема 4: Таймаут
**Решение:** Попробуйте снова, возможно, сервер перегружен

## Что прислать для диагностики

После попытки загрузки скопируйте из консоли:
1. Все логи, начинающиеся с `[evaluateImage]`
2. Все логи, начинающиеся с `[App]`
3. Все ошибки (красным цветом)

Это поможет точно определить проблему.
