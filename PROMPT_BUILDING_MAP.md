# КАРТА ПОСТРОЕНИЯ ПРОМПТОВ ДЛЯ НОВОГОДНИХ ФОТОСЕССИЙ

## ОБЩАЯ СТРУКТУРА

Система построения промптов состоит из следующих этапов:

1. **Анализ изображения** → Определение категории (66 категорий)
2. **Выбор базового шаблона** → Из CATEGORY_TEMPLATES
3. **Применение модуля стиля** → Из STYLE_MODULES (12 стилей)
4. **Применение модуля локации** → Из LOCATION_MODULES (25 локаций)
5. **Генерация вариаций** → Действия, позы, эмоции, композиция, освещение
6. **Генерация описания одежды** → В зависимости от возраста, пола, стиля
7. **Генерация инструкций сохранения** → Лица, телосложения, бороды/усов
8. **Определение ориентации** → Вертикальная/горизонтальная
9. **Сборка финального промпта** → Замена всех плейсхолдеров

## ЭТАП 2: БАЗОВЫЙ ШАБЛОН КАТЕГОРИИ

### Структура шаблона:

Каждый шаблон содержит:
- **description** - текстовое описание категории
- **template** - строка с плейсхолдерами для замены

### Плейсхолдеры в шаблоне:

- `[FACE_PRESERVATION]` - инструкция по сохранению лица (для одного человека)
- `[FACE_PRESERVATION_MULTIPLE]` - инструкция по сохранению лиц (для нескольких человек)
- `[BODY_PRESERVATION]` - инструкция по сохранению телосложения
- `[ATTIRE_DESCRIPTION]` - описание новогодней одежды
- `[ANIMAL_DESCRIPTION]` - описание животных (если есть)
- `[ANIMAL_DESCRIPTION_MULTIPLE]` - описание нескольких животных
- `[STYLE_MODULE]` - модуль стиля фотосессии
- `[LOCATION_MODULE]` - модуль локации
- `[ACTION_VARIATION]` - вариация действия
- `[POSE_VARIATION]` - вариация позы
- `[EMOTION_VARIATION]` - вариация эмоции (удаляется в финальном промпте)
- `[COMPOSITION_VARIATION]` - вариация композиции
- `[LIGHTING_VARIATION]` - вариация освещения
- `[CAMERA_SPECS]` - технические характеристики камеры

### Пример шаблона:

```javascript
'adult-woman-1': {
  description: 'Молодая женщина или девушка',
  template: `Молодая женщина (возраст ~20-40 лет) в новогоднем наряде. 
[FACE_PRESERVATION]
[BODY_PRESERVATION]
[ATTIRE_DESCRIPTION]
[STYLE_MODULE]
[LOCATION_MODULE]
[ACTION_VARIATION]
[POSE_VARIATION]
[EMOTION_VARIATION]
[COMPOSITION_VARIATION]
[LIGHTING_VARIATION]
[CAMERA_SPECS]
Фотографическое качество, естественное освещение, профессиональная съемка.`
}
```

## ЭТАП 3: МОДУЛИ СТИЛЕЙ (12 СТИЛЕЙ)

### Доступные стили:

1. **`family`** - Семейная новогодняя
   - Теплая семейная атмосфера
   - Традиционные новогодние элементы
   - Елка, подарки, праздничный стол

2. **`romantic`** - Романтическая новогодняя
   - Романтическая атмосфера для пар
   - Камин, шампанское, новогодние огни
   - Мягкое освещение

3. **`party`** - Праздничная вечеринка
   - Яркая, веселая атмосфера
   - Активные позы, смех, танцы
   - Конфетти, серпантин, колпаки

4. **`fairy-tale`** - Сказочная новогодняя
   - Волшебная атмосфера
   - Сказочные декорации
   - Дед Мороз, Снегурочка, магия

5. **`elegant`** - Элегантная новогодняя
   - Изысканная, стильная фотосессия
   - Элегантная одежда, классические позы
   - Роскошная елка, дорогие украшения

6. **`playful`** - Игривая новогодняя
   - Веселая, динамичная фотосессия
   - Активные движения, игры
   - Новогодние игрушки, снежки

7. **`cozy`** - Уютная домашняя новогодняя
   - Домашняя, комфортная атмосфера
   - Домашняя одежда, расслабленные позы
   - Домашняя елка, теплые пледы, чай

8. **`winter-tale`** - Зимняя сказка на улице
   - Морозная, снежная атмосфера
   - Зимняя одежда, снег, лед
   - Снег, ледяные фигуры, новогодние огни

9. **`glamorous`** - Гламурная новогодняя
   - Роскошная, шикарная фотосессия
   - Дорогая одежда, роскошные декорации
   - Роскошная елка, дорогие украшения

10. **`retro`** - Ретро новогодняя
    - Стилизация под 50-80е годы
    - Винтажная одежда, ретро-декорации
    - Винтажные игрушки, старинные украшения

11. **`midnight`** - Новогодняя ночь (полночь)
    - Торжественная атмосфера встречи Нового года
    - Бой курантов, фейерверки, шампанское
    - Часы, фейерверки, новогодний салют

12. **`children`** - Детская новогодняя
    - Волшебная атмосфера для детей
    - Детский восторг, игры, подарки
    - Детская елка, подарки от Деда Мороза

## ЭТАП 6: ГЕНЕРАЦИЯ ОПИСАНИЯ ОДЕЖДЫ

### Функция: `generateNewYearAttire(analysisResult, styleId, variationIndex, shouldAddHeadwear, shouldAddPatterns)`

**Входные параметры:**
- `analysisResult` - результат анализа изображения
- `styleId` - ID стиля (12 стилей)
- `variationIndex` - индекс промпта (0-5)
- `shouldAddHeadwear` - добавлять ли головные уборы (true/false)
- `shouldAddPatterns` - добавлять ли узоры на одежду (true/false)

### Структура NEW_YEAR_ATTIRE:

```
NEW_YEAR_ATTIRE
├── child
│   ├── girl[styleId] → Array<string> (10 вариантов одежды)
│   └── boy[styleId] → Array<string> (10 вариантов одежды)
├── adultWoman[styleId] → Array<string> (10 вариантов одежды)
├── adultMan[styleId] → Array<string> (10 вариантов одежды)
└── elderly
    ├── woman[styleId] → Array<string> (8 вариантов одежды)
    └── man[styleId] → Array<string> (8 вариантов одежды)
```

### Логика выбора одежды:

1. **Определение пула одежды:**
   - По возрасту: `child`, `adult`, `elderly`
   - По полу: `girl`/`boy`, `woman`/`man`
   - По стилю: `styleId` (12 стилей)

2. **Выбор уникальной одежды:**
   - Для каждого человека выбирается уникальная одежда
   - Используется формула: `(variationIndex + i * 6) % uniqueAttire.length`
   - Гарантирует разные одежды на каждом из 6 изображений

3. **Обработка узоров:**
   - По умолчанию все упоминания узоров удаляются из описания
   - Если `shouldAddPatterns === true`, добавляются узоры:
     - 'с вышитыми новогодними узорами (елочки, снежинки, звезды)'
     - 'с декоративными новогодними узорами (снежинки, елочные ветки)'
     - и т.д.

4. **Головные уборы:**
   - Если `shouldAddHeadwear === true`, добавляются головные уборы из `NEW_YEAR_HEADWEAR`
   - Выбираются уникальные головные уборы для каждого человека

### Структура NEW_YEAR_HEADWEAR:

```
NEW_YEAR_HEADWEAR
├── child
│   ├── girl → Array<string> (6 вариантов)
│   └── boy → Array<string> (5 вариантов)
├── adultWoman → Array<string> (8 вариантов)
├── adultMan → Array<string> (7 вариантов)
└── elderly
    ├── woman → Array<string> (4 варианта)
    └── man → Array<string> (4 варианта)
```

### Распределение головных уборов и узоров:

- **Узоры:** случайно на 0, 1 или 2 изображениях из 6
- Индексы выбираются случайно из [0, 1, 2, 3, 4, 5]

## ЭТАП 8: ОПРЕДЕЛЕНИЕ ОРИЕНТАЦИИ

### Функция: `determineOrientation(categoryId, styleId, locationId, peopleCount)`

**Логика:**

1. **1 человек:**
   - По умолчанию: **вертикальная**
   - Исключения (горизонтальная): `city-street`, `city-square`, `outdoor-rink`, `park`

2. **2 человека:**
   - По умолчанию: **вертикальная**
   - Исключения (горизонтальная): 
     - Стиль `romantic` → вертикальная
     - Локации: `city-street`, `city-square`, `outdoor-rink`, `park` → горизонтальная

3. **3 человека:**
   - По умолчанию: **горизонтальная**
   - Исключения (вертикальная): `photo-studio`

4. **4+ человека:**
   - **СТРОГО горизонтальная**, независимо от локации

### Правила разнообразия ориентации:

После определения базовой ориентации, система добавляет исключения для разнообразия:

- **Для 1-4 человек:** 1-2 промпта из 6 получают противоположную ориентацию
- Индексы исключений выбираются случайно из [0, 1, 2, 3, 4, 5]

## ЭТАП 9: СБОРКА ФИНАЛЬНОГО ПРОМПТА

### Функция: `buildNewYearPrompts(analysisResult, styleId, locationId)`

**Алгоритм:**

1. **Определение категории** → `categoryId`
2. **Получение шаблона** → `categoryTemplate.template`
3. **Получение модулей** → `styleModule.module`, `locationModule.module`
4. **Генерация инструкций сохранения** → `facePreservation`, `bodyPreservation`, `animalDescription`
5. **Определение головных уборов и узоров:**
   - Случайно выбираются индексы для головных уборов (0-2 изображения)
   - Случайно выбираются индексы для узоров (0-2 изображения)
6. **Определение базовой ориентации** → `baseOrientation`
7. **Планирование исключений ориентации** → `exceptionIndices` (1-2 промпта)
8. **Генерация 6 промптов:**
   ```javascript
   for (let i = 0; i < 6; i++) {
     // Определение финальной ориентации
     let finalOrientation = baseOrientation;
     if (exceptionIndices.includes(i)) {
       finalOrientation = baseOrientation === 'vertical' ? 'horizontal' : 'vertical';
     }
     
     // Выбор вариаций
     const variations = selectVariationsWithOrientation(...);
     
     // Генерация описания одежды
     const attireDescription = generateNewYearAttire(
       analysisResult, 
       styleId, 
       i, 
       headwearIndices.includes(i), 
       patternsIndices.includes(i)
     );
     
     // Замена плейсхолдеров
     let prompt = categoryTemplate.template;
     prompt = prompt.replace(/\[FACE_PRESERVATION\]/g, facePreservation);
     prompt = prompt.replace(/\[BODY_PRESERVATION\]/g, bodyPreservation);
     prompt = prompt.replace(/\[ATTIRE_DESCRIPTION\]/g, attireDescription);
     // ... и т.д.
     
     // Добавление инструкций об ориентации (в 3 местах промпта)
     prompt = `${orientationText} ${prompt}`;
     prompt = prompt.replace(/(\[LOCATION_MODULE\])/, `$1 ${orientationText}`);
     prompt += ` КРИТИЧЕСКИ ВАЖНО - ОРИЕНТАЦИЯ ФОТО: ...`;
     
     // Добавление инструкций о других людях/животных
     if (isOutdoorLocation) {
       prompt += ` КРИТИЧЕСКИ ВАЖНО: На переднем плане ТОЛЬКО люди и животные из исходного фото...`;
     } else {
       prompt += ` КРИТИЧЕСКИ ВАЖНО: На фото ТОЛЬКО люди и животные из исходного фото...`;
     }
     
     prompts.push({ prompt, orientation: finalOrientation, ... });
   }
   ```

### Структура финального промпта:

```
[ИНСТРУКЦИЯ ОБ ОРИЕНТАЦИИ] 
[ОПИСАНИЕ УЧАСТНИКОВ] 
[FACE_PRESERVATION] 
[BODY_PRESERVATION] 
[ATTIRE_DESCRIPTION] 
[ANIMAL_DESCRIPTION] 
[STYLE_MODULE] 
[LOCATION_MODULE] 
[ИНСТРУКЦИЯ ОБ ОРИЕНТАЦИИ (повтор)] 
[ACTION_VARIATION] 
[POSE_VARIATION] 
[COMPOSITION_VARIATION] 
[LIGHTING_VARIATION] 
[CAMERA_SPECS] 
[ИНСТРУКЦИЯ О ДРУГИХ ЛЮДЯХ/ЖИВОТНЫХ] 
[ИНСТРУКЦИЯ ОБ ОРИЕНТАЦИИ (повтор)] 
Фотографическое качество, естественное освещение, профессиональная съемка.
```

## ЗАВИСИМОСТИ И ВЗАИМОСВЯЗИ

### Зависимости от анализа изображения:

1. **Количество людей** → выбор категории, вариаций действий/поз, ориентация
2. **Возраст людей** → выбор категории, описание одежды, головных уборов
3. **Пол людей** → выбор категории, описание одежды, головных уборов, инструкции о бороде/усах
4. **Количество животных** → выбор категории, описание животных, добавление действий с животными
5. **Тип животных** → описание животных

### Зависимости от стиля:

1. **Стиль** → модуль стиля, описание одежды (10 вариантов на стиль), атмосфера

### Зависимости от локации:

1. **Локация** → модуль локации, ориентация (для уличных локаций), требования к одежде (теплая для улицы, формальная для театра), разрешение других людей на фоне (только для уличных)

### Зависимости от variationIndex (0-5):

1. **variationIndex** → уникальные вариации действий, поз, эмоций, композиции, освещения, камеры, одежды

## КРИТИЧЕСКИ ВАЖНЫЕ ИНСТРУКЦИИ В ПРОМПТАХ

- Ракурс головы идентичен исходному
- Выражение лица идентично исходному
- Направление взгляда идентично исходному

- Рост идентичен исходному
- Телосложение идентично исходному
- Пропорции тела идентичны исходному

- Инструкция повторяется 3 раза в промпте

## ЗАКЛЮЧЕНИЕ

Система построения промптов является многоуровневой и учитывает:
- Все параметры анализа изображения (количество, возраст, пол людей и животных)
- Выбранный стиль фотосессии (12 стилей)
- Выбранную локацию (25 локаций)
- Уникальные вариации для каждого из 6 промптов
- Строгие инструкции по сохранению узнаваемости
- Требования к ориентации и композиции

Каждый промпт генерируется индивидуально с учетом всех этих факторов, обеспечивая разнообразие и качество результатов генерации.
