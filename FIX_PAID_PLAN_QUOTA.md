# 🔧 Исправление проблемы с Free Tier вместо платного плана

## ❌ Проблема

В логах видно, что используется **Free Tier** квота, хотя у вас платный план:
- `generate_content_free_tier_requests`
- `quotaId: GenerateRequestsPerDayPerProjectPerModel-FreeTier`
- `limit: 0` - Free Tier лимит исчерпан

## ✅ Решение

### Шаг 1: Проверьте биллинг в Google Cloud Console

1. Откройте: https://console.cloud.google.com/billing
2. Убедитесь, что:
   - ✅ Биллинг **включен** для вашего проекта
   - ✅ Есть активная платежная карта
   - ✅ Нет проблем с оплатой

### Шаг 2: Проверьте проект API ключа

1. Откройте: https://console.cloud.google.com/apis/credentials
2. Найдите ваш API ключ (`AIzaSyClaX5nW3MFp56vWGQVFebdhzINDeLqb48` для анализа)
3. Проверьте:
   - ✅ Ключ создан в **правильном проекте** (с платным планом)
   - ✅ Проект имеет **включенный биллинг**

### Шаг 3: Проверьте квоты проекта

1. Откройте: https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com/quotas
2. Найдите квоты для `gemini-2.0-flash`
3. Убедитесь, что видны **платные квоты**, а не Free Tier

### Шаг 4: Пересоздайте API ключ (если нужно)

Если ключ был создан в Free Tier проекте:

1. Создайте новый проект с включенным биллингом
2. Включите Gemini API в новом проекте
3. Создайте новый API ключ
4. Обновите `GEMINI_API_KEY_ANALYSIS` на сервере

### Шаг 5: Проверьте настройки API

1. Откройте: https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com
2. Убедитесь, что:
   - ✅ API **включен**
   - ✅ Используется **платный план** (не Free Tier)

---

## 🔍 Как проверить текущий статус

1. Откройте: https://ai.dev/usage?tab=rate-limit
2. Войдите с аккаунтом, к которому привязан API ключ
3. Проверьте:
   - Какие квоты видны (Free Tier или платные)
   - Текущее использование
   - Лимиты

---

## ⚠️ Важно

- **Free Tier** и **платный план** - это разные проекты/настройки
- API ключ должен быть создан в проекте с **включенным биллингом**
- Даже если у вас платный план, ключ может быть привязан к Free Tier проекту

---

## 📝 После исправления

После того как исправите настройки:
1. Обновите API ключ на сервере (если создали новый)
2. Перезапустите backend контейнеры
3. Проверьте логи - должны исчезнуть ошибки Free Tier
