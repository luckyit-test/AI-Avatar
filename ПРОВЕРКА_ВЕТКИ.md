# 🔍 Проверка какая ветка на проде

## ❌ Проблема: SSH пароль не работает

Но есть несколько способов проверить ветку на проде:

## ✅ Способ 1: Через PuTTY (рекомендуется)

### Если PuTTY установлен:

1. Запустите файл **`check-prod-branch.bat`**
2. Он автоматически проверит ветку на проде

### Если PuTTY не установлен:

1. Скачайте и установите PuTTY: https://www.putty.org/
2. Запустите `check-prod-branch.bat`

## ✅ Способ 2: Ручная проверка через SSH

1. Откройте PowerShell
2. Выполните:
   ```bash
   ssh root@43.245.226.24
   ```
3. **Если пароль не работает**, попробуйте:
   - Проверить правильность пароля
   - Обратиться к администратору сервера
   - Использовать SSH ключ (если настроен)

4. На сервере выполните:
   ```bash
   cd /opt/newava
   git branch --show-current
   git log -1 --oneline
   git rev-parse HEAD
   ```

## ✅ Способ 3: Через GitHub Actions

Если GitHub Actions настроены:

1. Откройте: https://github.com/luckyit-test/AI-Avatar/actions
2. Найдите последний запуск workflow "deploy"
3. Проверьте логи - там будет видно какая ветка деплоилась

## ✅ Способ 4: Сравнение через веб-интерфейс

Если на сайте есть какая-то информация о версии:

1. Откройте: https://newava.pro/
2. Проверьте в исходном коде страницы (F12 → Sources)
3. Ищите признаки версии/коммита

## 📊 Что нужно проверить:

### Локально (у вас):
- Ветка: `avatar`
- Коммит: `16dd6e1 Add automatic deployment for avatar branch`

### На проде (должно быть):
- Ветка: `avatar` ✅
- Коммит: `16dd6e1 Add automatic deployment for avatar branch` ✅

## 🎯 Критерии успеха:

✅ **Деплой успешен**, если:
- Ветка на проде = `avatar`
- Коммит на проде совпадает с локальным (или новее)

❌ **Деплой не прошел**, если:
- Ветка на проде = `main` (или другая)
- Коммит на проде старый

## 🚀 Быстрая проверка:

Запустите файл **`check-prod-branch.bat`** - он покажет:
- Локальную ветку и коммит
- Ветку и коммит на проде (если PuTTY установлен)
- Сравнение результатов

## 💡 Если ничего не работает:

Обратитесь к администратору сервера с просьбой проверить:
```bash
cd /opt/newava
git branch --show-current
git log -1 --oneline
```
