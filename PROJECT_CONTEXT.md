# Контекст проекта AI Avatar

## Текущее состояние проекта

**Ветка**: `avatar`  
**Домен продакшена**: `newava.pro`  
**Последний коммит**: `c60f245` - Add Telegram bot for portrait generation

## Архитектура

### Frontend
- **Фреймворк**: React + TypeScript + Vite
- **Стилизация**: Tailwind CSS
- **Анимации**: Framer Motion
- **Основные компоненты**:
  - `App.tsx` - главный компонент приложения
  - `components/ImageUploadFlow.tsx` - загрузка изображений (Шаг 1)
  - `components/ImageConfiguration.tsx` - настройка параметров (Шаг 2)
  - `components/GenerationActions.tsx` - генерация портретов (Шаг 3)
  - `components/Footer.tsx` - подвал сайта
  - `components/GalleryPage.tsx` - страница галереи
  - `components/AnimatedPortraitsBackground.tsx` - анимированный фон с портретами

### Backend
- **Сервер**: Node.js + Express
- **API**: REST API с префиксом `/api`
- **Генерация изображений**: Google Gemini API (`gemini-2.5-flash-image`)
- **Обработка изображений**: Sharp (resize, format conversion, optimization)
- **База данных**: SQLite (заказы, промокоды)
- **Очередь генерации**: In-memory очередь с rate limiting

### Ключевые файлы сервера
- `server/index.js` - основной сервер, API endpoints
- `server/bot/telegram.js` - Telegram бот для генерации портретов
- `server/services/promptBuilder.js` - построение промптов для генерации
- `server/services/promptUtils.js` - утилиты для промптов (одежда, роли, компании)
- `server/services/portraitGeneration.js` - логика генерации портретов
- `server/services/imageProcessing.js` - предобработка изображений (denoise, background replacement)
- `server/db/orders.js` - работа с заказами
- `server/db/promocodes.js` - работа с промокодами

## Важные настройки

### Промпт для генерации
- **Модель**: `gemini-2.5-flash-image`
- **Стили**: 6 стилей (Классический, Современный, Креативный, Технологичный, Дружелюбный, Уверенный)
- **Особенности промпта**:
  - Максимальное сглаживание кожи (glossy magazine cover style)
  - Удаление пор, зернистости, шума
  - Сохранение закрытого рта (если закрыт в оригинале)
  - Легкое уменьшение полноты лица для полных людей
  - Запрет на показ оборудования для фотосъемки в кадре
  - Естественная глубина резкости фона (не слишком размыто)
  - Минимум 3 разных варианта одежды в подборке из 6 портретов

### Предобработка изображений
- **Удаление шума**: Медианный фильтр + легкое размытие + повышение резкости
- **Замена фона**: Серый градиент (RGB 128, 128, 128)
- **Размер**: 1024x1024 с сохранением пропорций

### Оптимизация изображений
- **Формат**: WebP с fallback на JPEG
- **Размеры**: Small (150px) для мобильных, Medium (200px) для десктопа
- **Качество**: JPEG quality 85 для оптимизированных версий
- **Lazy loading**: Intersection Observer для фоновых портретов
- **Сохранение**: JPEG quality 95, максимальный размер 2048px

### Оплата
- **Провайдер**: Robokassa
- **Стоимость генерации**: 200 ₽
- **Промокоды**: Поддерживаются через `/api/promo/use`

## API Endpoints

### Генерация
- `POST /api/generate-image` - генерация одного портрета
- `GET /api/generate-image/:jobId` - статус генерации
- `POST /api/promo/use` - генерация с промокодом (6 портретов)

### Валидация и анализ
- `POST /api/validate-image` - валидация изображения
- `POST /api/detect-gender` - определение пола
- `POST /api/evaluate-image` - полный анализ изображения

### Галерея
- `GET /api/gallery/recent` - последние портреты для фона
- `GET /api/gallery/orders` - заказы для галереи

### Оптимизация изображений
- `GET /api/images/optimized?url=...&size=...&format=...` - оптимизированные версии

## Telegram Bot

### Статус
- ✅ **Реализован и запущен** на продакшене
- **Файл**: `server/bot/telegram.js`
- **Токен**: Хранится в переменной окружения `TELEGRAM_BOT_TOKEN` на сервере

### Функциональность
- Команды `/start` и `/help`
- Автоматический анализ изображений и определение пола
- Генерация 6 портретов в разных стилях
- Отправка результатов пользователю

### Особенности
- Использует прямую генерацию через Gemini API (не через очередь)
- Не мешает работе основного веб-приложения
- Использует существующие сервисы: `promptBuilder`, `imageProcessing`, `validation`
- Фиксированные параметры: роль "Разработчик", компания "Стартап"

### Документация
- `TELEGRAM_BOT_SETUP.md` - подробная инструкция по настройке
- `TELEGRAM_BOT_QUICK_START.md` - быстрый старт
