# 🤖 Настройка Telegram бота для генерации портретов

## Описание

Telegram бот использует существующий движок генерации портретов из проекта `newava.pro`. Бот работает в том же процессе, что и основной сервер, но не мешает его работе, так как использует прямую генерацию через Gemini API (не через очередь).

## Архитектура

- **Файл бота**: `server/bot/telegram.js`
- **Интеграция**: Автоматически запускается при старте сервера, если указан токен
- **Используемые сервисы**:
  - `buildPortraitPrompts` - построение промптов для генерации
  - `replaceBackgroundWithGray` - предобработка изображений
  - `validateImageData` - валидация изображений
  - `analyzeImageForTelegram` - анализ изображений и определение пола
  - Прямая генерация через Gemini API (не использует очередь)

## Установка

### 1. Установка зависимостей

Зависимость `telegraf` уже добавлена в `package.json`. Установите её:

```bash
npm install
```

### 2. Создание Telegram бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 3. Настройка переменных окружения

Добавьте токен бота в файл `.env` или `.env.local`:

```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

**⚠️ ВАЖНО**: Не коммитьте файл `.env` в Git! Токен должен храниться только в переменных окружения.

### 4. Запуск сервера

Бот автоматически запустится при старте сервера, если токен указан:

```bash
npm run server
# или
node server/index.js
```

Если токен не указан, бот просто не запустится, и сервер продолжит работать как обычно.

## Использование

### Команды бота

- `/start` - Приветствие и инструкция по использованию
- `/help` - Справка по использованию бота

### Процесс генерации

1. Пользователь отправляет фото в бот
2. Бот анализирует изображение и определяет пол
3. Бот генерирует промежуточное изображение (замена фона на серый)
4. Бот генерирует 6 портретов в разных стилях последовательно
5. Бот отправляет все портреты пользователю

### Требования к изображению

- Фото должно быть одного человека
- Лицо должно быть четко видно
- Изображение должно быть фотографией реального человека (не рисунок, не 3D-рендер)

## Особенности реализации

### Изоляция от основного проекта

- Бот использует **прямую генерацию** через Gemini API, не использует очередь генерации
- Это означает, что бот не будет мешать работе основного веб-приложения
- Генерация для бота происходит последовательно с задержкой 2 секунды между запросами

### Использование существующих сервисов

Бот переиспользует:
- ✅ Логику построения промптов (`promptBuilder.js`)
- ✅ Предобработку изображений (`imageProcessing.js`)
- ✅ Валидацию изображений (`validation.js`)
- ✅ Анализ изображений для определения пола

### Ограничения

- Бот генерирует портреты с **фиксированными параметрами**:
  - Роль: "Разработчик"
  - Компания: "Стартап"
- В будущем можно добавить возможность выбора роли и компании через команды бота

## Логирование

Все действия бота логируются с префиксом `[Telegram Bot]`:

```
[Telegram Bot] Bot initialized successfully
[Telegram Bot] Bot started successfully
[Telegram Bot] Intermediate image generated
[Telegram Bot] Generating portrait 1/6: Классический
```

## Обработка ошибок

Бот обрабатывает следующие ошибки:
- Не удалось загрузить изображение из Telegram
- Изображение не подходит для генерации (не один человек, запрещенный контент)
- Не удалось определить пол
- Ошибки генерации портретов

При ошибке бот отправляет понятное сообщение пользователю и продолжает работу.

## Развертывание на продакшене

### Добавление токена на сервере

1. Подключитесь к серверу:
   ```bash
   ssh root@43.245.226.24
   ```

2. Перейдите в директорию проекта:
   ```bash
   cd /opt/newava
   ```

3. Добавьте токен в файл `.env`:
   ```bash
   echo "TELEGRAM_BOT_TOKEN=your_bot_token_here" >> .env
   ```

4. Перезапустите backend контейнер:
   ```bash
   docker compose restart backend
   ```

5. Проверьте логи:
   ```bash
   docker compose logs -f backend | grep "Telegram Bot"
   ```
