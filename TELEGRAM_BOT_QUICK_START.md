## ⚠️ Возможные проблемы

### Бот не запускается

**Проблема**: В логах нет сообщения "Telegram бот запущен"

**Решение**:
1. Проверьте, что токен правильно указан в `.env.local`
2. Проверьте формат токена (должен быть: `число:строка`)
3. Убедитесь, что файл `.env.local` находится в корне проекта

### Ошибка при установке telegraf

**Проблема**: Ошибки компиляции `better-sqlite3`

**Решение**: Это не критично. `telegraf` установится отдельно. Если проблемы продолжаются, попробуйте:
```bash
npm install telegraf --legacy-peer-deps
```

### Бот не отвечает

**Проблема**: Бот запустился, но не отвечает на сообщения

**Решение**:
1. Проверьте логи сервера на наличие ошибок
2. Убедитесь, что токен правильный (можно проверить через @BotFather командой `/token`)
3. Проверьте, что бот не заблокирован в Telegram
