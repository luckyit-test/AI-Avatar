# Детальная инструкция по настройке автоматического деплоя

## Проблема: 404 при попытке настроить секреты

Секреты GitHub настраиваются **не в ветке**, а в **настройках всего репозитория**. Вот правильный путь:

## Шаг 1: Настройка GitHub Secrets

### Где настраивать секреты:

1. Откройте репозиторий: https://github.com/luckyit-test/AI-Avatar
2. Перейдите в **Settings** (в верхнем меню репозитория, справа от "Code")
3. В левом меню выберите **Secrets and variables** → **Actions**
4. Нажмите **New repository secret**

### Какие секреты нужно добавить:

1. **VPS_HOST**
   - Значение: `43.245.226.24`

2. **VPS_USER**
   - Значение: `root`

3. **VPS_SSH_KEY**
   - Это приватный SSH ключ для доступа к серверу
   - Если у вас нет SSH ключа, см. раздел "Создание SSH ключа" ниже

4. **VPS_PORT** (опционально)
   - Значение: `22` (или оставьте пустым)

5. **APP_DIR** (опционально)
   - Значение: `/opt/newava` (или оставьте пустым)

6. **GEMINI_API_KEY** (обязательно)
   - Ваш ключ Gemini API

7. **DOMAIN** (опционально)
   - Значение: `newava.pro` (для SSL сертификата)

8. **SSL_EMAIL** (опционально, нужно если указан DOMAIN)
   - Email для Let's Encrypt

## Шаг 2: Создание SSH ключа для сервера

Если у вас нет SSH ключа, создайте его:

### На Windows (PowerShell):

```powershell
# Создайте SSH ключ
ssh-keygen -t rsa -b 4096 -f "$env:USERPROFILE\.ssh\github_deploy" -N '""'

# Покажите публичный ключ (нужно добавить на сервер)
Get-Content "$env:USERPROFILE\.ssh\github_deploy.pub"
```

### Добавьте публичный ключ на сервер:

1. Скопируйте содержимое публичного ключа (из команды выше)
2. Подключитесь к серверу:
   ```bash
   ssh root@43.245.226.24
   # Пароль: Yd2Vc_Wejus0DlNB
   ```
3. Выполните на сервере:
   ```bash
   mkdir -p ~/.ssh
   echo "ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ" >> ~/.ssh/authorized_keys
   chmod 600 ~/.ssh/authorized_keys
   chmod 700 ~/.ssh
   ```

### Добавьте приватный ключ в GitHub Secrets:

1. Откройте приватный ключ:
   ```powershell
   Get-Content "$env:USERPROFILE\.ssh\github_deploy"
   ```
2. Скопируйте **весь** ключ (включая `-----BEGIN RSA PRIVATE KEY-----` и `-----END RSA PRIVATE KEY-----`)
3. Добавьте в GitHub Secrets как `VPS_SSH_KEY`

## Шаг 3: Проверка настроек

После настройки всех секретов:

1. Перейдите в **Actions** в репозитории
2. Найдите workflow "deploy"
3. Нажмите **Run workflow** → выберите ветку `avatar` → **Run workflow**
