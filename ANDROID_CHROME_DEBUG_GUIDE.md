# Подробная инструкция: Отладка Android Chrome на компьютере

## Метод 1: USB отладка (рекомендуется)

### Шаг 1: Включите режим разработчика на Android

1. Откройте **Настройки** на телефоне
2. Перейдите в **О телефоне** (или **О системе**)
3. Найдите пункт **Номер сборки** (или **Версия MIUI** для Xiaomi)
4. **Нажмите на "Номер сборки" 7 раз подряд**
5. Появится сообщение "Вы стали разработчиком!" (или похожее)

### Шаг 2: Включите отладку по USB

1. Вернитесь в **Настройки**
2. Найдите новый раздел **Для разработчиков** (или **Параметры разработчика**)
3. Включите переключатель **Отладка по USB** (USB debugging)
4. При первом включении появится предупреждение - нажмите **ОК**

### Шаг 3: Подключите телефон к компьютеру

1. Подключите телефон к компьютеру через **USB кабель**
2. На телефоне появится запрос "Разрешить отладку по USB?"
3. Поставьте галочку **"Всегда разрешать с этого компьютера"**
4. Нажмите **Разрешить**

### Шаг 4: Откройте Chrome DevTools на компьютере

1. На компьютере откройте браузер **Google Chrome**
2. В адресной строке введите: `chrome://inspect`
3. Нажмите Enter
4. Убедитесь, что стоит галочка **"Discover USB devices"** (вверху страницы)

### Шаг 5: Найдите ваш телефон

1. В списке **"Remote Target"** должен появиться ваш телефон
2. Рядом будет название устройства (например, "Poco F5")
3. Под ним будет список открытых вкладок Chrome на телефоне
4. Найдите вкладку с сайтом **https://newava.pro/**
5. Нажмите кнопку **"inspect"** рядом с этой вкладкой

### Шаг 6: Откройте консоль

1. Откроется окно DevTools (как на обычном Chrome)
2. Перейдите на вкладку **"Console"** (Консоль)
3. Теперь все логи с телефона будут видны здесь!

### Шаг 7: Попробуйте загрузить фото

1. На телефоне попробуйте загрузить фото
2. В консоли на компьютере появятся логи
3. Ищите записи, начинающиеся с `[App]` и `[evaluateImage]`

## Метод 2: Удаленная отладка через Wi-Fi (без USB)

### Шаг 1: Подключите телефон и компьютер к одной Wi-Fi сети

### Шаг 2: Включите отладку по USB (как в Методе 1, шаги 1-2)

### Шаг 3: Подключите через USB (только для настройки)

1. Подключите телефон к компьютеру через USB
2. Разрешите отладку по USB

### Шаг 4: Включите отладку по сети

1. В Chrome на компьютере откройте `chrome://inspect`
2. Нажмите **"Port forwarding"** (или "Проброс портов")
3. Поставьте галочку **"Enable port forwarding"**
4. Добавьте порт: `9222` → `localhost:9222`

### Шаг 5: Отключите USB и используйте Wi-Fi

1. Отключите USB кабель
2. Телефон должен остаться в списке устройств
3. Теперь можно отлаживать по Wi-Fi!

## Метод 3: Eruda (самый простой, без компьютера)

### Шаг 1: Добавьте Eruda на сайт

Откройте на телефоне сайт https://newava.pro/

### Шаг 2: В адресной строке введите:

```
javascript:(function () { var script = document.createElement('script'); script.src = '//cdn.jsdelivr.net/npm/eruda'; document.body.appendChild(script); script.onload = function () { eruda.init(); } })();
```

### Шаг 3: Нажмите Enter

1. Внизу экрана появится панель Eruda
2. Нажмите на иконку **Console** (консоль)
3. Теперь все логи будут видны прямо на телефоне!

## Что искать в консоли

После загрузки фото ищите:

### 1. Информация о файле:
```
[App] File selected: {
  name: "IMG_2024.jpg",
  size: 5242880,
  sizeMB: "5.00",
  type: "image/jpeg",
  ...
}
```

### 2. Начало проверки:
```
[evaluateImage] Starting evaluation: {
  apiBaseUrl: "https://newava.pro/api",
  imageDataLength: 6990500,
  estimatedSizeMB: "6.67",
  ...
}
```

### 3. Ошибки (если есть):
```

  error: "timeout",
  errorName: "Error",
  mappedMessage: "Не удалось связаться с сервером...",
  ...
}
```

```

  name: "TypeError",
  message: "Failed to fetch",
  ...
}
```

## Возможные проблемы и решения

### Проблема: Телефон не появляется в chrome://inspect

**Решения:**
1. Убедитесь, что включена отладка по USB
2. Попробуйте другой USB кабель
3. Установите драйверы для вашего телефона
4. На телефоне разрешите отладку при появлении запроса

### Проблема: "inspect" не работает

**Решения:**
1. Убедитесь, что сайт открыт в Chrome на телефоне
2. Обновите страницу `chrome://inspect`
3. Попробуйте закрыть и открыть вкладку на телефоне

### Проблема: Нет логов в консоли

**Решения:**
1. Убедитесь, что консоль открыта (вкладка Console)
2. Очистите консоль (кнопка с иконкой перечеркнутого круга)
3. Попробуйте загрузить фото снова

## Альтернатива: Скриншоты консоли

Если не получается подключиться:

1. Используйте **Eruda** (Метод 3)
2. Сделайте **скриншоты** консоли с логами
3. Пришлите скриншоты для анализа

## Быстрая проверка

После подключения:

1. Откройте консоль
2. Введите: `console.log('Test')`
3. Нажмите Enter
4. Если в консоли появилось "Test" - все работает!

---

**Рекомендация:** Начните с **Метода 3 (Eruda)** - это самый простой способ увидеть логи прямо на телефоне без подключения к компьютеру.
