# 🔐 Решение проблемы с паролем SSH

## ❌ Проблема: "Permission denied" при подключении

Пароль не подходит, но **сайт работает** (HTTP 200) - это означает, что:
- ✅ Деплой был успешным ранее
- ✅ Сервер работает
- ❌ Пароль SSH мог измениться или есть другие ограничения

## ✅ Решения:

### Вариант 1: Проверка через веб-интерфейс (самый простой)

1. Откройте в браузере: **https://newava.pro/**
2. Если сайт открывается и показывает ваше приложение - деплой успешен!
3. Проверьте функциональность приложения

### Вариант 2: Использование GitHub Actions (рекомендуется)

Если пароль SSH не работает, используйте автоматический деплой через GitHub Actions:

1. Настройте GitHub Secrets (см. `DEPLOY_SETUP_GUIDE.md`)
2. Каждый коммит и пуш в ветку `avatar` будет автоматически деплоиться
3. Проверяйте статус: https://github.com/luckyit-test/AI-Avatar/actions

### Вариант 3: Проверка через веб-интерфейс сервера

Если у вас есть доступ к панели управления сервером (например, Timeweb Cloud):
- Проверьте статус контейнеров через веб-интерфейс
- Проверьте логи через веб-интерфейс

### Вариант 4: Обращение к администратору

Если у вас нет доступа к SSH:
- Обратитесь к администратору сервера
- Попросите проверить:
  - Активную ветку: `cd /opt/newava && git branch --show-current`
  - Последний коммит: `cd /opt/newava && git log -1 --oneline`
  - Статус контейнеров: `cd /opt/newava && docker compose ps`

## 🔍 Проверка успешности деплоя БЕЗ SSH:

### 1. Проверка сайта:
```bash
# Откройте в браузере
https://newava.pro/
```

### 2. Проверка через curl:
```bash
curl -I https://newava.pro/
# Должен вернуть HTTP 200
```

### 3. Проверка функциональности:
- Откройте сайт
- Проверьте основные функции приложения
- Если все работает - деплой успешен!

## 📊 Признаки успешного деплоя:

- ✅ Сайт https://newava.pro/ открывается
- ✅ HTTP статус: 200
- ✅ Приложение работает корректно
- ✅ Нет ошибок на странице
