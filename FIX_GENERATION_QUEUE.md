# 🔧 Исправление проблемы с генерацией на hnyear.com

## Проблема

Генерация изображений "зависает" - джоб создается, но не обрабатывается.

## Причина

При обработке промежуточного изображения (`Change background to gray`) возникает ошибка:
```
Error: Image to composite must have same dimensions or smaller
```

После ошибки код должен был продолжить обычным способом через API, но этого не происходило из-за неправильной обработки исключения.

## Исправление

Исправлена обработка ошибок в `server/index.js` - после ошибки обработки промежуточного изображения код теперь продолжает выполнение и добавляет джоб в очередь для обычной генерации через API.

## Что проверить

1. Попробуйте загрузить фото снова на https://hnyear.com/
2. Проверьте логи: `docker compose logs -f backend | grep -i "processJob\|generate\|queue"`
3. Убедитесь что джобы обрабатываются
