- ❌ Нет оптимизации для landscape режима на мобильных
- ❌ Нет специальной версии для планшетов (iPad)
- ⚠️ Некоторые компоненты не адаптируются на маленьких экранах
- ⚠️ Промокод input может быть слишком узким на мобильных

#### 3. **Touch взаимодействия**

- ❌ Нет свайп-жестов для навигации между портретами

## 📱 Специфичные проблемы iOS Safari

### 1. **Viewport и безопасные зоны**
```html
<!-- Текущий viewport -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<!-- Рекомендуемый viewport для iOS -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=5.0, user-scalable=yes, viewport-fit=cover">
```

### 2. **Контекстное меню и выделение текста**
```css
/* Нужно добавить */
-webkit-touch-callout: none;
-webkit-user-select: none;
user-select: none;
```

### 3. **Touch жесты**
```css
/* Нужно добавить */
touch-action: manipulation; /* Предотвращает двойной тап для зума */
```

### 4. **Безопасные зоны (notch)**
```css
/* Нужно добавить для iPhone X+ */
padding-top: env(safe-area-inset-top);
padding-bottom: env(safe-area-inset-bottom);
padding-left: env(safe-area-inset-left);
padding-right: env(safe-area-inset-right);
```

### 5. **HEIC формат**
- Текущая реализация: только проверка с предупреждением
- Рекомендация: добавить автоматическую конвертацию через библиотеку `heic2any` или серверную конвертацию
